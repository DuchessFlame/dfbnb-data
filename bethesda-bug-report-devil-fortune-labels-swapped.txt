TITLE
The Devil fortune notes have their Upright/Reversed titles swapped (Lady G Fortune Teller)

WHERE
Server: Public Test Server (PTS)
World:  Public Adventure

DESCRIPTION
In the Nuka-World on Tour Lady G the Fortune Teller system, every Major Arcana card exists as an Upright note (Lucky Fortune, +2 Luck) and a Reversed note (Un-Lucky Fortune, -2 Luck). For The Devil, the two notes have their orientation titles swapped. The note in the Lucky/Positive pool that grants +2 Luck is titled "Fortune: The Devil - Reversed", and the note in the Un-Lucky/Negative pool that grants -2 Luck is titled "Fortune: The Devil - Upright". This is backwards compared to all 21 other Major Arcana, where Upright = Lucky and Reversed = Un-Lucky. For comparison, The Sun is labelled correctly: NWOT_FortuneMajor_TheSun_Positive (0066D157) sits in the Lucky pool (+2 Luck) and is titled "Fortune: The Sun - Upright", while NWOT_FortuneMajor_TheSun_Negative (0066D159) sits in the Un-Lucky pool (-2 Luck) and is titled "Fortune: The Sun - Reversed". The Devil should follow that same pattern but doesn't. The Luck buff still applies correctly for the pool the note is drawn from — only the printed orientation label on the note is wrong. Records affected: NWOT_FortuneMajor_TheDevil_Positive (0066D147) is titled "Reversed"; NWOT_FortuneMajor_TheDevil_Negative (0066D14F) is titled "Upright".

STEPS TO REPRODUCE
1. Travel to the Nuka-World on Tour carnival and speak to Lady G the Fortune Teller.
2. Pay 50 caps per reading until you draw The Devil in both orientations (or inspect the BOOK records directly).
3. Compare the orientation shown in each Devil note's title against the Luck buff it grants.
4. Note that the +2 Luck (Lucky) Devil reads "Reversed" and the -2 Luck (Un-Lucky) Devil reads "Upright".

EXPECTED
The Lucky/Positive Devil note (+2 Luck) should be titled "Fortune: The Devil - Upright", and the Un-Lucky/Negative Devil note (-2 Luck) should be titled "Fortune: The Devil - Reversed" — matching every other Major Arcana card.

ACTUAL
The titles are reversed: the +2 Luck Devil note reads "Reversed" and the -2 Luck Devil note reads "Upright".

PLATFORM
All Platforms

PATCH
Nuka-World on Tour PTS (Patch 14)

REPRO RATE
10/10

AREA / DEPARTMENT
System Design

POSSIBLE CAUSE / SUGGESTED FIX
The FULL (title) strings on the two Devil BOOK records appear swapped relative to their fortune-pool membership. NWOT_FortuneMajor_TheDevil_Positive (0066D147), which sits in the Positive/Lucky pool, is titled "- Reversed"; NWOT_FortuneMajor_TheDevil_Negative (0066D14F), which sits in the Negative/Un-Lucky pool, is titled "- Upright". Swap the two title strings so the Positive note reads "Upright" and the Negative note reads "Reversed".
